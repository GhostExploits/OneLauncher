# Code of Conduct

SpiderClient is a small project built around trust and careful work.

## Expected behavior

- Be direct about technical problems without attacking the person who wrote the
  code.
- Respect device ownership, privacy, and consent. Never help add covert
  monitoring, credential theft, or unauthorized remote control.
- Give credit for upstream work and follow the licensing and branding terms in
  [ATTRIBUTION.md](./ATTRIBUTION.md).
- Keep secrets out of issues, pull requests, screenshots, and logs.

## Unacceptable behavior

- Harassment, discrimination, threats, or sustained personal attacks.
- Publishing another person's tokens, account files, logs, or private device
  information.
- Deliberately submitting misleading diagnostics, fake test results, or
  concealed network activity.
- Attempting to bypass authorization, rate limits, signing, or ownership checks.

## Reporting

Report a security or conduct issue privately to the project owner rather than
posting exploit details publicly. Maintainers may remove content, reject
contributions, or revoke access to project spaces when these expectations are
violated.

This is a project-specific code of conduct, not a claim of affiliation with a
third-party covenant organization.
